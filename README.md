
# Verbal Harassment Detection Using NLP

## Project Overview

An NLP-based machine learning system designed to detect potentially harassing or toxic language in verbal communication.

The project initially focuses on text classification and will later integrate automatic speech recognition to process audio input.

## Objectives

- Develop a binary text classification model.
- Compare Logistic Regression and Linear SVM.
- Evaluate model performance using precision, recall and F1-score.
- Integrate Whisper for speech-to-text conversion.
- Build a simple interface for testing predictions.

## Proposed Architecture

Audio → Whisper → Text → TF-IDF → ML Classifier → Prediction
